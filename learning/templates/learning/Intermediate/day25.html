📖 3. Reading Activity · The Design Review

What distinguishes a great engineer from a merely competent one is not the ability to perform calculations, but the capacity to communicate the implications of those calculations to decision-makers. It is this translational skill — converting technical data into actionable insight — that is in shortest supply in the profession. The reason many engineering projects fail is not technical incompetence but a breakdown in communication between engineers and stakeholders. What is needed, therefore, is a curriculum that treats communication as a core engineering competency.

Meaning: To do something perfectly

🧠 Grammar Hack: Cleft Sentences — 4 Types

}All that-cleft}The reason-cleft
Type Structure Example
It-cleft It + is/was + emphasis + that/who + rest It is the design that needs revision.
What-cleft What + clause + is/was + emphasis What we need is more testing time.
All that + clause + is/was + emphasis All that is required is a brief review.
The reason + result + is that + cause The reason the project succeeded is that the team communicated effectively.

⚠️ Activity: Rewrite these as cleft sentences (each using a different type):

1. 'The project manager solved the problem.' (Use It-cleft: It was + person + who + action)

2. 'We need more data before deciding.' (Use What-cleft: What + we need + is + more data)

3. 'The insulation failed. That caused the fire.' (Use The reason-cleft: The reason + fire + was that + insulation failed)
